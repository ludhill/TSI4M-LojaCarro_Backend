🛠️ Arquitetura de Implantação e Deploy em Produção

Esta seção documenta os procedimentos técnicos necessários para acoplar esta interface gráfica Single-Page Application (SPA) ao ecossistema do seu projeto Spring Boot desenvolvido no IntelliJ IDEA, além de mapear as diretrizes de empacotamento seguro para distribuição em instâncias de nuvem como a AWS.

📂 Incorporação Estrutural no IntelliJ IDEA

O Spring Boot possui suporte nativo para servir arquivos estáticos localizados em diretórios específicos do seu classpath. Siga as etapas abaixo para integrar este front-end de forma transparente:

  1. Abra o seu projeto LojaCarro no IntelliJ.
  2. Navegue até o diretório de recursos da aplicação: src/main/resources.
  3. Verifique se existe uma pasta chamada static. Caso não exista, clique com o botão direito em resources -> New -> Directory e nomeie como static.
  4. Crie um arquivo dentro dela chamado index.html.
  5. Abra o arquivo, cole a totalidade deste código HTML e salve as alterações.
  6. Inicie o backend executando a classe principal LojaCarroApplication.java.
  7. Abra o navegador e acesse a URL da aplicação: http://localhost:8080/index.html.

☁️ Diretrizes de Build e Distribuição AWS

Para garantir estabilidade, segurança e portabilidade total ao publicar o artefato final gerado pela sua suíte Maven em servidores AWS, atente-se às seguintes configurações de infraestrutura:

📦 Compilação de Artefato: Execute o comando .\mvnw clean package para unificar este arquivo HTML dentro do arquivo executável final .jar.

⚙️ Versionamento de Runtime: Configure o ambiente AWS (Elastic Beanstalk, EC2 ou Docker) obrigatoriamente com a plataforma Java 17 (Amazon Corretto 17) para evitar exceções de classe incompatível.

🔒 Portabilidade de Rede: Certifique-se de expor a porta 8080 nos Grupos de Segurança (Security Groups) da AWS para permitir tráfego HTTP de entrada vindo da internet.
